# Learnings

- [2026-10-07] [claude] Claude Design `.dc.html` exports depend on `support.js`, which loads React + Babel from unpkg and compiles the page in the visitor's browser — port to static HTML/CSS/JS before shipping; never deploy the `.dc.html` as-is.
- [2026-10-07] [claude] Images downloaded from the Claude Design file pane can be tiny thumbnails (72x48 px); pull the original `src` URLs from the `.dc.html` instead and check dimensions before using them.
- [2026-10-07] [claude] Claude Design `position: sticky` headings inside an auto-fit grid stick to the whole grid, so when it collapses to one column on mobile they slide over the content below — gate sticky behind a min-width media query. Full-page screenshots at scroll 0 never show this; screenshot mid-section.
- [2026-10-07] [claude] Google Fonts failed to load on the client's phone (fallback fonts shown) — self-host woff2 (latin + latin-ext) from the start; also avoids the EU GDPR issue with Google Fonts.
- [2026-10-07] [claude] Google Apps Script web apps reject CORS preflight — POST with `fetch(url, {method:'POST', body: JSON.stringify(data)})` and NO custom headers (sent as text/plain, a "simple" request) and the JSON response is readable; adding `Content-Type: application/json` breaks it.
- [2026-10-07] [claude] Apps Script `appendRow` treats strings starting with `= + - @` as formulas — prefix guest input with `'` to avoid spreadsheet formula injection.
- [2026-10-07] [claude] (Superseded — switched to Vercel + Apps Script) Netlify Forms only detects forms present in the static HTML at deploy time — a JS-rendered multi-step form needs a hidden twin `<form name="rsvp" data-netlify="true">` with the same field names, then POST urlencoded with `form-name` to `/`.
- [2026-10-07] [claude] Calendar links: serve real `.ics` files as `text/calendar` without a `download` attribute — iOS Safari then shows "Add to Calendar"; `data:` URIs with `download` save to Files instead.
- [2026-10-22] [claude] Claude Code cloud sessions run behind a network policy that (by default) blocks michelleandpa.com, pamichellewedding.vercel.app and script.google.com, so curl/Playwright cannot hit the live site or the Apps Script from there. Verify deploys through the Vercel connector instead (list_deployments shows the commit SHA and READY state), and add those hosts under Allowed domains in the environment settings when a live end-to-end test is needed.
- [2026-10-22] [claude] The Google Drive connector can create the RSVP Google Sheet in the signed-in account, and the Gmail connector can confirm the notification email arrived, but the Apps Script part (paste Code.gs, script properties, Deploy as web app, OAuth consent) has no API path from the connectors and must be done by a person in the Apps Script editor.
- [2026-10-24] [claude] When Google Fonts is unreachable from the cloud session, the `@fontsource/<font>` npm package (registry.npmjs.org is always allowed) ships the same woff2 subsets. Its per-subset CSS has no `unicode-range`, so copy the latin / latin-ext ranges from the existing fonts.css.
- [2026-10-24] [claude] Swapping a font family: index.html and guests.html each carry a `<link rel="preload">` for the italic woff2; a stale one gives a silent 404 (Playwright `response` listener catches it, visual checks do not).
- [2026-10-24] [claude] vercel.json caches `/assets/*` for 7 days, so after changing fonts.css (or any asset) bump a query string on its link in index.html and guests.html, otherwise returning phones keep the old file and show fallback fonts.
- [2026-10-24] [claude] Apps Script "New deployment" opens on API Executable, not Web app (gear icon next to "Select type"), and the consent screen needs "Select all" ticked or the deploy works but MailApp/Sheets calls fail. The consent screen shows the Apps Script project name, so rename "Untitled project" first.
- [2026-10-24] [claude] Apps Script `getRange(...).setValues()` on a found row is the simplest "upsert" for a sheet used as a database; matching on a normalised name (not email, which is optional on the form) lets "Edit reply" replace the row instead of duplicating it.
